## 🚀 Featured Projects

<div align="center">

### 👁️ Eye Tracking Cursor Control

</div>

> **Assistive Technology · Computer Vision · Human-Computer Interaction**

A hands-free computer control system designed to empower users with physical disabilities, enabling seamless interaction with computers using only eye movement and blink gestures.

<table>
<tr>
<td width="60%">

**✨ Key Features**
- 👁️ Real-time eye tracking using facial landmark detection
- 🖱️ Cursor movement mapped to gaze direction
- 👁️‍🗨️ Blink-based click simulation (single & double blink)
- 🎯 Custom calibration module for precision tuning
- ♿ Designed for users with mobility impairments

</td>
<td width="40%">

**🔧 Tech Stack**

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white)
![MediaPipe](https://img.shields.io/badge/MediaPipe-0097A7?style=flat-square&logo=google&logoColor=white)
![PyAutoGUI](https://img.shields.io/badge/PyAutoGUI-FFD43B?style=flat-square&logo=python&logoColor=black)

</td>
</tr>
</table>

**🏗️ Architecture Overview**

```
Camera Feed → OpenCV Frame Capture
     ↓
MediaPipe Face Mesh → 468 Facial Landmarks
     ↓
Eye Region Extraction → Iris/Blink Detection Algorithm
     ↓
Coordinate Mapping → PyAutoGUI Cursor Control
     ↓
Calibration Module → Precision Enhancement
```
